Cómo se registra la firma

Formas admitidas para registrar la firma que se estampa al aprobar un consolidado. Quien no tenga registrada una firma de alguna de las formas marcadas, la registra en el momento de firmar.

Al firmar se puede elegir entre subir una imagen o dibujarla, y basta tener registrada cualquiera de las dos. Si hay ambas, se estampa la imagen.

Solo se acepta «{{ label(activos[0]) }}». A quien tenga registrada únicamente la otra forma se le pedirá esta la primera vez que firme.

Tiene que quedar al menos una marcada: por eso la última no se puede desmarcar.
